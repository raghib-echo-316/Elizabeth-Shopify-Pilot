# Suggestions

Small tips from Claude while you build. **Claude does not change your theme code.** It only writes suggestions here, and you make the changes yourself.

## How it works

- Each file is one session or topic, named `YYYY-MM-DD-topic.md`.
- Every suggestion has:
  - **Where**: the file and line
  - **What I noticed**
  - **Why it matters**
  - **How to try it yourself**: steps or a hint, not a finished fix
- When you've handled one, tick its box `[x]`, or add a note with what you learned.

## Priority labels

- 🔴 **Fix**: something is broken, or customers will notice
- 🟡 **Improve**: works now, but could be better (accessibility, performance, editor experience)
- 🟢 **Learn**: a concept worth understanding; no change needed
